# ⚡ PhotoPicker - 极速挑图 Web 应用

纯前端 Web 应用,专为摄影师设计的快速选片工具。

## ✨ 核心功能

- **极速导入** - 支持文件夹导入 2000+ 张图片,秒级加载
- **多列对比** - 2/3/5 列自由切换,并排对比图片
- **三分类系统** - 正确✅ / 适中⚖️ / 错误❌ 快速分类
- **原图导出** - 按分类导出到文件夹,保留原始文件名
- **键盘操作** - 快捷键支持,无需鼠标即可完成挑图

## 🚀 技术栈

- **React 18** - UI 框架
- **Vite** - 极速开发和构建
- **Tailwind CSS** - 原子化 CSS
- **react-window** - 虚拟滚动 (处理 2000+ 图片)
- **Zustand** - 轻量状态管理
- **File System Access API** - 浏览器文件夹读写

## 🎯 使用方法

### 1. 导入图片

点击 **"📁 导入文件夹"** 按钮,选择包含图片的文件夹。

- 支持递归读取子文件夹
- 支持格式: JPG, PNG, WebP, RAW 等
- 2000+ 图片秒级加载

### 2. 切换列数

点击工具栏的 **"2列"/"3列"/"5列"** 按钮,切换对比模式。

- 2列 - 左右对比
- 3列 - 三图对比 (默认)
- 5列 - 多图对比

### 3. 分类图片

**方法一:鼠标操作**
- 悬停图片,显示分类按钮
- 点击对应按钮进行分类

**方法二:键盘快捷键 (推荐)**
- `1` - 标记为"✅ 正确" (绿色)
- `2` - 标记为"⚖️ 适中" (黄色)
- `3` - 标记为"❌ 错误" (红色)
- `0` - 取消分类
- `←/→` - 切换上/下一张图片

### 4. 导出图片

完成分类后,点击 **"💾 导出"** 按钮:

1. 选择导出目标文件夹
2. 自动创建 3 个子文件夹:
   - `正确/` - 包含所有标记为"正确"的图片
   - `适中/` - 包含所有标记为"适中"的图片
   - `错误/` - 包含所有标记为"错误"的图片
3. 原图复制,保留原始文件名

## 🌐 浏览器兼容性

**✅ 支持:**
- Chrome 86+
- Edge 86+

**❌ 不支持:**
- Firefox (File System Access API 未实现)
- Safari (File System Access API 未实现)

> **提示:** File System Access API 是 Chrome/Edge 专有的浏览器 API,用于文件夹读写。Firefox 和 Safari 暂不支持。
