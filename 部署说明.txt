  • 网址格式：https://photo-picker.vercel.app

方案 3: Netlify（备选）

  • 缺点：需要国际网络注册
  • 网址格式：https://photo-picker.netlify.app

🚀 快速部署步骤（方案 1: GitHub Pages）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【第 1 步】创建 GitHub 账号（如果已有可跳过）
  1. 访问 https://github.com/signup
  2. 填写邮箱、密码，完成注册

【第 2 步】创建 GitHub 仓库
  1. 访问 https://github.com/new
  2. Repository name: photo-picker
  3. 勾选 Public（公开）
  4. 不勾选 README
  5. 点击 "Create repository" 按钮

【第 3 步】推送代码到 GitHub
  在项目文件夹（photo-picker）打开终端，运行：

  # 配置 Git（首次使用需要）
  git config --global user.name "你的名字"
  git config --global user.email "你的邮箱"

  # 添加远程仓库（把 YOUR_USERNAME 改成你的 GitHub 用户名）
  git remote add origin https://github.com/YOUR_USERNAME/photo-picker.git

  # 推送代码
  git add .
  git commit -m "🎉 筛图神器首次部署"
  git push -u origin main

  ⚠️ 如果提示需要登录，输入 GitHub 用户名和密码（或 Token）

【第 4 步】启用 GitHub Pages
  1. 打开你的 GitHub 仓库页面
     https://github.com/YOUR_USERNAME/photo-picker
  2. 点击 "Settings"（设置）
  3. 左侧菜单找到 "Pages"
  4. Source 选择 "GitHub Actions"
  5. 保存

【第 5 步】等待部署完成
  1. 点击仓库的 "Actions" 标签
  2. 看到绿色 ✅ 表示部署成功（约 2-3 分钟）
  3. 如果是红色 ❌，点击查看错误日志

【第 6 步】访问你的网站
  https://YOUR_USERNAME.github.io/

  例如：https://jiliying.github.io/

❓ 常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: 部署后网站打不开？
A: 等待 2-3 分钟让部署完成，清除浏览器缓存后重试

Q: 显示 404 错误？
A: 检查 GitHub Pages 设置，Source 必须是 "GitHub Actions"

Q: git push 提示权限错误？
A: 需要配置 GitHub Token：
   1. GitHub → Settings → Developer settings → Personal access tokens
   2. Generate new token (classic)
   3. 勾选 repo 权限
   4. 生成后复制 Token
   5. git push 时用 Token 作为密码

Q: 文件夹导入不工作？
A: 必须使用 Chrome 或 Edge 浏览器（Firefox/Safari 不支持）
