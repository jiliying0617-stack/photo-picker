Photo Picker 浏览器扩展 - 安装步骤
═══════════════════════════════════════════════════════

【步骤 1】在 Chrome 中加载扩展
────────────────────────────────────────────────

1. 打开 Chrome 浏览器

2. 在地址栏输入并访问：
   chrome://extensions/

3. 启用右上角的 "开发者模式" 开关

4. 点击 "加载已解压的扩展程序"

5. 在弹出的文件选择器中，选择这个文件夹：
   /Users/jiliying/Desktop/photo-picker/browser-extension

   （这个窗口已经打开了！）

6. 点击 "选择" 按钮

7. 复制扩展 ID（重要！）
   在扩展卡片上找到类似这样的 ID：
   abcdefghijklmnopqrstuvwxyz123456


【步骤 2】安装 Native Host
────────────────────────────────────────────────

1. 打开终端（Terminal）

2. 执行以下命令：
   cd /Users/jiliying/Desktop/photo-picker/browser-extension
   bash install-native-host.sh

3. 脚本会提示输入扩展 ID
   粘贴步骤 1 复制的 ID，按回车

4. 等待显示 "✅ 安装完成！"


【步骤 3】重启 Chrome
────────────────────────────────────────────────

⚠️ 重要：必须完全退出 Chrome 并重新打开

方法 1（推荐）：
  在终端运行：killall "Google Chrome"
  然后手动打开 Chrome

方法 2：
  Chrome 菜单 → 退出 Chrome（Cmd+Q）
  不是关闭窗口，而是退出应用！


【步骤 4】测试
────────────────────────────────────────────────

1. 打开 Photo Picker:
   http://localhost:5173

2. 导入照片文件夹

3. 右键点击照片

4. 选择 "在访达中显示"

5. 文件位置应该自动在访达中打开！🎉
